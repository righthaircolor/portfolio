# Портфолио Ксении Анискович

Статичный сайт: чистые HTML, CSS и немного JS. Весь текст и картинки лежат в Notion, на странице **«Сайт — админка»**.

## Как поменять что-то на сайте

1. Правишь текст в Notion:
   - **Главная**: тексты под заголовками. Сами заголовки не переименовывай, по ним сайт понимает, что куда ставить. Если под заголовком пусто, блок на сайте скрывается.
   - **Проекты**: одна строка — один проект.
     - «Показывать»: галочка.
     - «Блок»: «Проекты» или «Своё».
     - «Порядок»: число, чем меньше, тем выше.
     - Внутри страницы проекта пишешь подробности и вставляешь картинки. Это показывается в боковой панели. Если страница пустая, строка ведёт сразу на «Ссылку».
   - **Опыт**: строки блока под фото.
   - **Обо мне**: пишется как обычный документ, сайт сам раскладывает текст по колонкам:
     - первый абзац — крупное приветствие;
     - заголовок H2 — подпись раздела капсом в узкой левой колонке;
     - заголовок H3 и текст под ним — подзаголовок слева, текст справа;
     - две колонки Notion — левая колонка ложится в узкую колонку сайта, правая в основную;
     - разделитель (`/divider` или `---`) — тонкая линия; без него линий нет;
     - всё остальное идёт в основную колонку. Название страницы — подпись в шапке.
2. Сайт пересобирается сам раз в час. Чтобы обновить сразу: вкладка **Actions** → «Собрать сайт из Notion» → **Run workflow**.

## Первая настройка (один раз)

1. **Ключ Notion.** Открой https://www.notion.so/profile/integrations → New integration → тип Internal, название «Сайт». Скопируй *Internal Integration Secret*.
2. **Доступ к админке.** В Notion открой «Сайт — админка» → ••• (справа вверху) → Connections → добавь интеграцию «Сайт».
3. **Секрет в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret. Имя `NOTION_TOKEN`, значение — ключ из шага 1.
4. **Включить Pages.** Settings → Pages → Source: **GitHub Actions**.
5. Actions → «Собрать сайт из Notion» → Run workflow. Через 1–2 минуты сайт будет на `https://<логин>.github.io/<репозиторий>/`.

Свой домен: впиши его в `site.config.json` → `"domain"` и настрой DNS по инструкции GitHub Pages.

## Если что-то пошло не так

Actions → последний запуск → красный шаг «npm run build». Ошибки там написаны по-русски: например, «нет доступа к странице» означает, что не сделан шаг 2.

GitHub выключает запуск по расписанию, если в репозитории 60 дней не было коммитов. Тогда обновляй кнопкой Run workflow или включи расписание обратно в Actions.

## Для разработки

```
npm install
npm run build:fixture   # собрать из fixtures/content.json, без Notion
npm test
NOTION_TOKEN=... npm run build
```

- `scripts/notion.mjs`: запросы к Notion API.
- `scripts/content.mjs`: Notion → простая модель. Здесь же список заголовков «Главной».
- `scripts/render.mjs`: HTML-шаблоны.
- `src/`: стили, скрипт, шрифты.
