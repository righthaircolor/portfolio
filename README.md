# Портфолио Ксении Анискович

Статичный сайт: чистые HTML, CSS и немного JS. Весь текст и картинки лежат в Notion, на странице **«Сайт — админка»**.

## Как поменять что-то на сайте

1. Правишь текст в Notion:
   - **Главная**: тексты под заголовками. Сами заголовки не переименовывай, по ним сайт понимает, что куда ставить. Если под заголовком пусто, блок на сайте скрывается.
   - **Проекты**: одна строка — один проект.
     - «Показывать»: галочка.
     - «Блок»: «Проекты», «Своё» или «Спецпроекты». Любое новое значение «Блока» станет на главной ещё одной таблицей после «Своё» — с таким же заголовком, по образцу «Проектов».
     - «Порядок»: число, чем меньше, тем выше.
     - «Картинка при наведении» (необязательно): перетащи в это поле PNG или JPG — при наведении мыши на строку картинка появится рядом с курсором, ~160px по ширине, пропорции сохраняются. На телефоне не показывается.
     - Внутри страницы проекта пишешь подробности и вставляешь картинки. Это показывается в боковой панели. Если страница пустая, строка ведёт сразу на «Ссылку».
   - **Опыт**: строки блока под фото.
   - **Обо мне**: пишется как обычный документ, сайт сам раскладывает текст по колонкам:
     - первый абзац — крупное приветствие;
     - заголовок H2 — подпись раздела капсом в узкой левой колонке;
     - заголовок H3 и текст под ним — подзаголовок слева, текст справа;
     - две колонки Notion — левая колонка ложится в узкую колонку сайта, правая в основную;
     - три колонки Notion — первая в узкую колонку (можно оставить пустой), вторая и третья — две колонки внутри основной;
     - разделитель (`/divider` или `---`) — тонкая линия; без него линий нет;
     - всё остальное идёт в основную колонку. Название страницы — подпись в шапке.
   - **Кейсы и наблюдения** (`/journal/`): слева фраза (текст страницы в Notion), рубрики и список материалов; справа лента карточек-превью в том же порядке. Материалы — база **«Тексты»** внутри этой страницы, одна строка — один материал:
     - «Порядок» необязателен. Пустой — материал наверху (новые выше). Число — место в списке: меньше — выше; между 2 и 3 ставится 2.5; одинаковые числа можно (новее — выше). Перенумеровывать остальное не нужно. «Показывать» — галочка.
     - «Рубрика» — пункт меню слева. В меню все варианты «Рубрики» в том порядке, в каком они стоят в Notion (перетаскиваются); новая рубрика = новый вариант. Пустая рубрика показывает «Здесь скоро появятся тексты».
     - «Где» — издание под названием и в кнопке «Читать в «…» →»; «Год» — необязательно, пишется рядом с изданием.
     - «Кратко» — описание в карточке.
     - «Превью» — картинка в карточке: перетащи файл в это поле (и для внешних материалов, и для текстов на сайте). Пусто — карточка без картинки.
     - «Текст ссылки» — надпись на кнопке в карточке. Пусто — «Читать в «Где»» для внешних и «Читать» для текстов на сайте. Стрелку → сайт добавит сам.
     - «Ссылка» заполнена — карточка ведёт туда (новая вкладка). «Ссылка» пустая, а внутри страницы есть текст — он станет страницей сайта `/journal/<название>/`: слева фраза и рубрики (ведут обратно в список), справа название, под ним «Где» и «Год», дальше текст по правилам «Обо мне». Крестик возвращает к карточке в списке.
     - Название страницы «Статьи, заметки, инсайты» в Notion — подпись в шапке сайта.
2. Сайт пересобирается сам каждые 15 минут (GitHub иногда задерживает такие запуски на час-другой). Чтобы обновить сразу: вкладка **Actions** → «Собрать сайт из Notion» → **Run workflow**.

## Первая настройка (один раз)

1. **Ключ Notion.** Открой https://www.notion.so/profile/integrations → New integration → тип Internal, название «Сайт». Скопируй *Internal Integration Secret*.
2. **Доступ к админке.** В Notion открой «Сайт — админка» → ••• (справа вверху) → Connections → добавь интеграцию «Сайт».
3. **Секрет в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret. Имя `NOTION_TOKEN`, значение — ключ из шага 1.
4. **Включить Pages.** Settings → Pages → Source: **GitHub Actions**.
5. Actions → «Собрать сайт из Notion» → Run workflow. Через 1–2 минуты сайт будет на `https://<логин>.github.io/<репозиторий>/`.

Свой домен: впиши его в `site.config.json` → `"domain"` и настрой DNS по инструкции GitHub Pages.

## Если что-то пошло не так

Actions → последний запуск → красный шаг «npm run build». Ошибки там написаны по-русски: например, «нет доступа к странице» означает, что не сделан шаг 2.

GitHub выключает запуск по расписанию, если в репозитории 60 дней не было коммитов. Тогда обновляй кнопкой Run workflow или включи расписание обратно в Actions.

## Правки в коде: через ветки и превью

Код в `main` = то, что на сайте. Любые изменения вёрстки делаются в отдельной ветке:

1. Claude (или ты) создаёт ветку и загружает туда правки.
2. Через 2–3 минуты превью ветки появляется по адресу `righthaircolor.github.io/portfolio/preview/<название-ветки>/` — с чёрной плашкой «Превью» внизу слева. Все превью: [/preview/](https://righthaircolor.github.io/portfolio/preview/).
3. Превью собирается из того же Notion, так что там твои актуальные тексты.
4. Если всё нравится: на GitHub вкладка **Pull requests** → нужный запрос → **Merge pull request**. Через пару минут правки на основном сайте.
5. После слияния нажми **Delete branch** — превью исчезнет.

Если ветка сломана, у неё просто не будет превью; основной сайт это не затрагивает.

## Фавиконка

Лежит в `src/favicon.svg`. Чтобы заменить: на GitHub открой папку `src` → Add file → Upload files → загрузи свой SVG с именем `favicon.svg` → Commit changes. PNG-версии (`favicon-32.png`, `apple-touch-icon.png`) для Safari и экрана телефона нужно пересобрать — попроси об этом Claude.

## Для разработки

```
npm install
npm run build:fixture   # собрать из fixtures/content.json, без Notion
npm test
NOTION_TOKEN=... npm run build
```

- `scripts/notion.mjs`: запросы к Notion API.
- `scripts/content.mjs`: Notion → простая модель. Здесь же список заголовков «Главной».
- `scripts/render.mjs`: HTML-шаблоны.
- `src/`: стили, скрипт, шрифты.
