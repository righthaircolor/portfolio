# Как работать с этим репозиторием

Сайт-портфолио Ксении Анискович: статичный HTML, контент из Notion («Сайт — админка»), хостинг GitHub Pages.
Подробности для человека — в README.md.

## Правила внесения правок
- **Не коммить в main напрямую.** Каждая правка — отдельная ветка (`git checkout -b короткое-название`), пуш, затем pull request в main.
- После пуша ветки её превью собирается само: `https://righthaircolor.github.io/portfolio/preview/<ветка>/`
  (имя ветки в нижнем регистре, всё кроме `a-z0-9-` заменяется на `-`). Список всех превью: `/preview/`.
- Дай Ксении ссылку на превью и PR; в main сливает она сама кнопкой Merge. После слияния ветку удаляем — превью исчезает.
- Перед пушем: `npm test` и `npm run build:fixture`, посмотреть `dist/` в браузере (десктоп 1440 и телефон 390).

## Устройство
- `scripts/notion.mjs` — Notion API; `scripts/content.mjs` — Notion → модель; `scripts/render.mjs` — HTML; `src/` — CSS/JS/шрифты.
- `scripts/build-all.sh` — сборка в Actions: сайт из main + превью всех веток. Публиковать на Pages можно только из main,
  поэтому `.github/workflows/preview.yml` на пуш в ветку просто запускает `build.yml` на main.
- Отступы — только через токены в `:root` (`--s-list` 8, `--s-para` 16, `--s-group` 24, `--s-top` 32, `--s-block` 48).
- Шрифт один: Golos Text. Подписи разделов — капсом. Линии-разделители на «Обо мне» только там, где в Notion стоит divider.
